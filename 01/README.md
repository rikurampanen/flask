# Vaihe 1 – Projektin perustaminen

Ensimmäiseksi luodaan Flask-projekti.

## Projektikansio

```text
elokuvasivusto/
Virtuaaliympäristö
```

## Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

## macOS/Linux:

```bash
python -m venv .venv
source .venv/bin/activate
```
## Flaskin asentaminen

```python
pip install flask
```
## Opiskelijan tavoite

Tässä vaiheessa opitaan:
- mikä projekti on
- mikä virtuaaliympäristö on
- miten Python-paketti asennetaan
- miten Flask-projekti aloitetaan
